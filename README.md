# Королевство Рахита III (NeoForge 1.21.1, Java 21)

## Установка (5 минут)
1. Скачайте официальный шаблон **NeoForge MDK 1.21.1** (github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle).
2. В `gradle.properties` поставьте `mod_id=rakhit`, `mod_group_id=com.rakhit.kingdom`, `mod_name=Kingdom of Rakhit III`.
3. Удалите из шаблона `src/main/java/...` (пример-классы) и `src/main/resources/META-INF/neoforge.mods.toml`
   (в шаблоне он генерируется из `src/main/templates`, можно оставить его и подставить id `rakhit` - либо просто
   положить мой файл, удалив шаблонную папку templates и строку generateModMetadata).
4. Скопируйте из этого архива папки `src/main/java` и `src/main/resources`.
5. `./gradlew runClient` - тест, `./gradlew build` - jar в `build/libs`.

## Как это работает
- При первом запуске мира в ~64 блоках от спавна строится королевство (покои, сцена позора, тюрьма на 4 камеры,
  банк, хомячье колесо, забор с воротами). Координаты: `/rakhit where`, телепорт для оп: `/rakhit tp`.
- Территория неразрушима и незастраиваема (взрывы тоже ничего не ломают). Игроки в творческом режиме обходят защиту и наказания.
- Указ каждые 2 минуты (45 штук, перемешиваются без повторов). Объявление: title+subtitle, чат-свиток, босс-бар с таймером,
  "печатная машинка" в action bar, колокол, частицы. `/rakhit decree` (оп) - выдать следующий указ сразу.
- Нарушение -> офицерская карета (минекарт + офицер-житель) -> одно из наказаний:
  тюрьма 50-100 с (40%), хомячье колесо 45 с (30%), сцена позора 30 с с яйцами (25%), КАЗНЬ (5%).
- Нарушения вне указов: ломать/ставить блоки на территории, входить в королевские покои, вредить свиньям.
- Банк: касса (блок `rakhit:bank_teller`) в банке. ПКМ с алмазами - вложить всю стопку (Shift - один), ПКМ пустой - забрать выплату/статус.
  Раунд 5 минут: с шансом 20% банк лопается (алмазы -> корона Короля), иначе вклад +25%.
- Корона (`rakhit:crown`, надевается на голову) - иммунитет к указам и наказаниям. Хлыст (`rakhit:whip`) - ПКМ, 4.0 урона (2 сердца), дальность 7.
- Рецепты: корона = 4 золотых блока + звезда Незера + алмазный блок; хлыст = 3 кожи + палка. Меняйте в `data/rakhit/recipe`.

## Что настраивать
- `Decrees.INTERVAL` - период указов; `Bank.BURST_CHANCE` / `Bank.INTEREST`; веса наказаний - `Justice.punish`.
- Новые указы - добавьте строку `s(...)` (проверка состояния) или `e(..., Kind.X)` (событие) в `Decrees`.
- Ассеты генерирует `gen_assets.py` (Pillow + ffmpeg); можно заменить файлы своими.
